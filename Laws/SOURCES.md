# Sources

## Downloaded from bdcode.gov.bd (2026-09-13)

Curated from the [Bangladesh Code Chronological Index](https://bdcode.gov.bd/bangladesh-code-chronological-index.html)
(1064 acts total across all volumes, 1799-2011). Scope was narrowed to acts
relevant to criminal law/procedure — see entry-assessment.md's "Code of
Criminal Procedure + relevant amendments and related laws" scope — rather
than the full index, which is mostly civil, tax, corporate, and
administrative law.

The Code of Criminal Procedure, 1898 itself is not on this index (it
predates or sits outside this particular Code project's volumes); the
existing `The Code of Criminal Procedure, 1898 (Act No. V of 1898).pdf` and
`Bangladesh-Code_of_criminal_procedure.pdf` in this folder cover it.

Every file above was spot-checked or fully verified (first-page text
extraction) against its claimed title before being kept. Two candidates were
deliberately excluded because the source site's title and linked PDF didn't
match: "The Borstal Schools Act, 1928" (linked to `The-Forest-Act,-1927.pdf`)
and "The Railways Act, 1890" (linked to `The-Excise-(Malt-Liquors)-Act,-1890.pdf`).
Also excluded as out of scope: narrow regional/wartime regulations (e.g.
Chittagong Hill-Tracts industrial-area rules, 1942 Armed Forces ordinances),
and acts unrelated to criminal law (e.g. Commercial Documents Evidence Act).

## Pre-existing files (renamed for clarity, 2026-09-13)

All PDFs originally named after their source URL (`bdlaws.minlaw.gov.bd_*.pdf`,
`Bangladesh-Code_of_criminal_procedure.pdf`) were renamed to their actual act
title, identified by extracting and checking each file's first page. Where a
renamed file duplicates an act already listed above under a different source,
`(bdlaws.minlaw.gov.bd copy)` is appended so both copies keep unique
filenames rather than colliding or silently overwriting one another:

- **The Code of Criminal Procedure, 1898** — three copies now: `(Act No. V
  of 1898).pdf` (original, 11MB scan), `(bdcode.gov.bd copy).pdf`, and
  `(bdlaws.minlaw.gov.bd copy).pdf`.
- **Duplicated acts** (also downloaded fresh from bdcode.gov.bd above): The
  Penal Code 1860, The Police Act 1861, The Prisons Act 1894, The Prisoners
  Act 1900, The Control of Disorderly and Dangerous Persons (Goondas) Act
  1954 — each now has a plain-named bdcode.gov.bd copy and a
  `(bdlaws.minlaw.gov.bd copy)` file.
- **Not otherwise present, kept under their real names** (citizenship/
  immigration law, not criminal law): The Naturalization Act 1926, The
  Borstal Schools Act 1928, The Citizenship Act 1951, The Bangladesh
  Citizenship (Temporary Provisions) Order 1972, The Bangladesh Passport
  Order 1973.

Renaming only, no dedup: the same act still exists twice under some
filenames in this folder. Worth removing one copy of each before ingestion
so it isn't indexed twice — ask before deleting, since these weren't all
downloaded by the same process.
